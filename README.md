# 🧠 NeuroBridge

A simulated Brain–Computer Interface (BCI) platform for assistive communication.

## 🚀 Features
- EEG signal simulation
- Neural intent decoding UI
- Real-time feedback system
- Medical condition explorer
- Canvas-based neural network animation

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- Canvas API

## 🌐 Deployment
Deploy easily using Vercel:
1. Push to GitHub
2. Import project in Vercel
3. Click Deploy
